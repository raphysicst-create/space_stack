# 스페이스 스택: 화학 생존

카드를 쌓아 화학 반응을 일으키고, 10 Sol(일) 동안 우주기지에서 생존하는 브라우저 게임입니다.

**▶ 바로 플레이: https://raphysicst-create.github.io/space_stack/**

## 게임 방법

- 카드를 드래그해 다른 카드 위에 겹치면 **스택**으로 쌓입니다.
- 레시피 조건을 만족한 스택은 자동으로 반응이 시작되고, 진행 바가 다 차면 생성물 카드가 나옵니다.
- 우주비행사는 **매일(1 Sol = 60초) 산소(O₂) 1개**를 소비합니다. 산소가 없으면 체력이 1 줄어듭니다.
- 체력 3이 모두 떨어지면 실패, 10 Sol을 버티면 성공입니다.

## 화학 반응 레시피

| 반응 | 필요 카드 | 결과 | 소요 시간 |
|---|---|---|---|
| 얼음 녹이기 | 얼음 덩어리 + 대원 | 물 (얼음은 3회까지 사용) | 3초 |
| 과산화수소 분해 | H₂O₂ ×2 + MnO₂(촉매) + 대원 | H₂O ×2 + O₂ | 3초 |
| 물의 전기분해 | H₂O ×2 + 전기에너지 | H₂ ×2 + O₂ | 4초 |

태양열 발전기는 30초마다 전기에너지 카드를 하나씩 생산합니다.

## 실행

의존성 없는 단일 HTML 파일입니다. `index.html`을 브라우저로 열기만 하면 됩니다.
